Stop rebuilding the production backend every time you ship an agent. Every serious AI team builds the same internal platform — identity, approvals, memory, model routing, audit. Rya is that platform, built once.

The platform

Ten primitives. Each composable.

Small, sharp building blocks bound to a durable agent identity. None of them is the kind of thing a customer should have to rebuild.

Identity

Who the agent is, who owns it, what it may do — the contract everything else derives from.

Runtime

Durable execution that pauses, resumes, retries, and times out — and survives restarts.

Memory

Key-value, collections, and vector retrieval — scoped and addressable, not a context window.

Tools

Typed, permissioned tool calls with a full audit trail. The agent never sees a raw credential.

Approvals

Human-in-the-loop as a primitive. A run pauses durably, a human approves, the run resumes.

Events & jobs

Webhooks, cron, delayed work, retries with backoff, and a dead-letter queue.

Channels

Slack, email, and webhooks behind one interface. New channels arrive at the platform.

Model gateway

Anthropic, OpenAI, and custom models — permissioned, versioned, and traced per call.

Observability

Every run is a forensic trace. Token and cost accounting on every model call.

Isolation

Postgres row-level security. Tenant and per-user isolation enforced by the database itself.

The artifact

One declarative file is the contract.

The agent is defined in rya.agent.yaml — validated before any deploy, reviewable in a pull request.

rya.agent.yaml
name: support-followup-agent
runtime: python
model:
  provider: anthropic
  default: claude-haiku-4-5
tools:
  - id: crm.lookup
    permission: allowed
  - id: email.send
    permission: approval_required   # gated on a human
memory:
  collections: [conversations, customer_context]
triggers:
  - id: daily-followups
    type: cron
    schedule: "0 9 * * *"
approvals:
  default: required_for_external_actions

Built for coding agents

The coding agent is a first-class developer.

The dashboard exists, but it isn't the primary interface. Claude Code, Codex, and Cursor drive Rya end to end — and never have to guess.

CLI

Every command speaks --json with stable error codes and semantic exit codes. One binary: create, dev, deploy, runs trace, approvals approve.

MCP server 19 tools

The same surface as Model Context Protocol tools, so an agent can introspect, configure, deploy, and debug in its native idiom.

Skills

Progressive-disclosure knowledge bundles that teach the workflow up front — so agents stop discovering state by trial and error.

SDK py · ts

Python define_agent() with a typed runtime context, and a typed TypeScript client. Agent code is business logic; everything around it is the platform.

Deployment

Single-tenant. In your cloud. No shared blast radius.

We do not run a multi-tenant SaaS. Each customer gets a dedicated deployment inside their own account — reproducible in CloudFormation, owned end to end.

Your account

Cognito, Fargate, RDS, ElastiCache and Secrets Manager — described as code. You own the stack and can leave with it intact.

Identity at the edge

RS256 JWTs verified on every request. Mutating writes re-validate the caller before touching data — the agent holds no privileged credentials.

Human in control

Approvals gate external actions by default. Every run leaves a complete, queryable audit trail.
