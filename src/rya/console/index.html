Tool registry

Model gateway
Foundation and custom models, permissioned and versioned. Every call is logged.
Channels
How events arrive and messages go out — one interface across surfaces.
Connected credentials
Scoped credentials per provider — encrypted at rest, injected into tool calls at runtime, and enforced by the intersection rule (required ⊆ connection ∩ user). The secret is redacted from every trace and never returned to the agent.
Runs & traces
Every run is a forensic record — input event, every tool and model call, approvals, retries, final status.
Conversations
Durable sessions & messages — inbound events map to a thread by channel + external id, so replies land in context across restarts. Conversation storage and retrieval, not a chat product.
Approvals
External actions pause here. Approving resumes the real run — durably, from any worker.
Jobs & cron
Background work the runtime owns — schedules, retries with backoff, and a dead-letter queue.
Queue & durable turns
Durable jobs claimed by external workers in any language — leases, retries with backoff, dead-letter, cancellation. Chat turns are queue jobs too: click one to inspect its durable stream.
