Tool registry
Every tool the agent can reach — typed, permissioned, audited. Credentials resolve in the runtime; the agent never sees them.
Memory
Durable, scoped state — addressable by the agent, isolated per user by row-level security.
Knowledge
RAG — ingested documents, chunked + embedded, that the agent retrieves over with ctx.knowledge.search.
Model gateway
Foundation and custom models, permissioned and versioned. Every call is logged.
Channels
How events arrive and messages go out — one interface across surfaces.
Connected credentials
Scoped credentials per provider — encrypted at rest, injected into tool calls at runtime, and enforced by the intersection rule (required ⊆ connection ∩ user). The secret is redacted from every trace and never returned to the agent.
Runs & traces
Every run is a forensic record — input event, every tool and model call, approvals, retries, final status.
Environments
An environment is a pointer to one immutable, content-hashed version. Promote flips it, rollback flips it back, and in-flight runs finish on the version they pinned.

Versions
A version is content, not a name: one bundle hash, recorded once, promotable into any environment. A version is retained for as long as a run is pinned to it.

Workers
Execution-plane processes — one per (workspace, agent, version). They start on demand, scale to zero when their queue is empty, and pay a cold start on the next run.

Quota & usage
What this workspace is allowed to consume, and what it is consuming. A tenant cannot raise its own limits — that is the point of a quota.

Conversations
Durable sessions & messages — inbound events map to a thread by channel + external id, so replies land in context across restarts. Conversation storage and retrieval, not a chat product.
Approvals
External actions pause here. Approving resumes the real run — durably, from any worker.
Jobs & cron
Background work the runtime owns — schedules, retries with backoff, and a dead-letter queue.
Queue & durable turns
Durable jobs claimed by external workers in any language — leases, retries with backoff, dead-letter, cancellation. Chat turns are queue jobs too: click one to inspect its durable stream.
